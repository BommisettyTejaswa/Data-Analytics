About

This project is a professional web application for heart disease risk prediction.

It uses a structured dataset and machine learning workflow to deliver predictive insights, model evaluation, and patient-level reporting.

Dataset

The data includes patient features such as age, gender, chest pain type, blood pressure, cholesterol, blood sugar, ECG results, heart rate, exercise angina, oldpeak, ST slope, and heart disease label.

Technologies

Python, Flask, Pandas, Scikit-learn, Plotly, and ReportLab.

Workflow

Load the dataset, analyze the distribution, train models, compare performance, and predict heart disease risk for new patients.

Developer

Built as an AI/ML portfolio project with a polished medical-themed UI.
