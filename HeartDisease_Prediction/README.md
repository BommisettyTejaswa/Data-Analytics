# Heart Disease Prediction System

A professional web application for heart disease prediction using Python, Flask, and machine learning.

## Features
- Dataset overview and exploration
- Model training and comparison
- Heart disease prediction for new patients
- Model performance insights
- PDF prediction report download

## Setup
```bash
pip install -r requirements.txt
python app.py
```

Open `http://localhost:8501` in your browser.

## Project Structure
- dataset/heart.csv: heart disease dataset
- models/: trained model artifacts
- templates/: HTML templates for the Flask app
- static/css/: UI styling
- utils/: preprocessing, training, prediction, and visualization helpers
